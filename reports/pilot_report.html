Deeper analysis

Same capacitance, different zero point

Fitting σ = C·ΔU + σ₀ per structure separates two very different things: how strongly it charges per volt (the slope C), and where its own zero-charge point sits relative to μ₀ (the intercept σ₀).

Slope: double-layer capacitance

µC/cm² per volt — nearly identical across all three

Intercept → implied PZC shift from T

−σ₀/slope, in volts
Reading

The three slopes sit within 7% of each other (−11.1 to −11.9 µC/cm²/V) — in this continuum model, double-layer capacitance is set mostly by the electrolyte (1 M, RION=4 Å), not by which atomic defect sits at the interface.

What the defect changes is the intercept: at the same target potential as T's own zero-charge point, A1-fcc still carries +0.82 µC/cm² — equivalent to a PZC shifted about +0.07 V from the flat terrace. V1's shift is smaller, about +0.01 V. A raised adatom perturbs the local work function more than a missing atom does, at least on this unrelaxed geometry.

Open items

Before this feeds a production batch

  • Independently integrating RHOB+RHOION matches the CP loop's own charge at ΔU=0 but gives an implausibly large number at ΔU≠0 — likely a normalization detail specific to the multi-round CP loop, not traced yet. Don't use that field for K_D / enrichment integrals until it is.
  • Write the formal reports/pilot_summary.md the project spec requires before any production batch can start.
  • 4-layer slabs are a documented low-cost pretest, not a validated production thickness — a 4 / 6 / 8-layer convergence check is still owed.
  • Relax V1 and A1-fcc at ΔU=0 (small symmetry-breaking perturbation on mobile atoms, fixed seed) before any enrichment analysis — today's 9 points are all on unrelaxed, idealized geometry.
  • Compute V2, V3, V7, A1-hcp, A3 for real — they're geometry only above.
  • If the pilot passes: expand to the ±0.4 V points for the main 40-point reference matrix.
