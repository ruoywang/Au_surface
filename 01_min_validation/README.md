# 01_min_validation

两个算例，共用同一份几何（`_shared/T_flat/`，4×4×6 Au(111)，96原子，平整无缺陷，单侧边界），**都没有提交**。按顺序跑：

1. **`T_flat_neutral_pzc/`**（先跑这个）——`LCEP=.FALSE.`，`NELECT` 用中性默认值（q_e=0），其余单侧窗口/`ISOL=2` 溶剂设置不变。目的：拿到中性参考点的 `EFERMI`，对齐到液相体相后作为 `mu0`（v2 §4.2）。
2. **`T_flat_placeholder_mu/`**（第一步跑完、拿到 `mu0` 之后再跑/再改）——`LCEP=.TRUE.`, `NESCHEME=3`，测试恒电势机制本身（§00_audit 里的开放问题）。里面的 `TARGETMU=-4.6` 目前还是代码自带的占位默认值，等第一步出了 `mu0` 应该换成 `mu0 + ΔU` 里的某个真实值。

## 这次改动记录（相对上一版）

- **液区/真空高度**：v2 文档"40Å液区+20Å真空"（第94行）核实后**没有任何推导依据**，不是显式水的类比，就是没标来源的起点数字。改用1M电解质的德拜长度（λ_D≈3.0Å）重新估：几个德拜长度(~15Å)覆盖屏蔽衰减 + ~5Å体相平台 + 窗口过渡缓冲 → **液区20Å、真空10Å**。仍然只是起点，最终要靠 §5 的平台判据（SION/SDIEL>0.999、电势变化<1mV等）实测确认，不是现在就能定的终值。
- **金属位置**：底部Au层从贴着周期边界（原来只留0.5Å）改成上移到留 **5Å** 真空间隙。
- **DIPOL**：不再用"可动Au原子平均分数坐标"这种算出来的值，直接用 **`0.5 0.5 0.5`**——按审计结论这只是多极矩参考点、不是跳跃面位置，加上金属已经不贴边界，这个简单选择没问题。
- 新的 `SOL_Z0=14.653 Å`、`SOL_Z1=37.067 Å`（对应新的 `z_top_au=17.067 Å`），派生的 `ION_Z0/ION_Z1=16.653/35.067 Å`，总 `Lz=47.067 Å`（原来是72.567 Å）。

其余占位值（`a0=4.180 Å`、`R_SOLV/R_DIEL/NC_K/SIGMA_K/A_K` 用代码默认值）不变，仍然是待核实项，见各目录 `INCAR` 内联注释和 `00_audit/parameter_map.md`。
